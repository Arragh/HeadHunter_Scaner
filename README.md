# HeadHunter Scaner

## 🚀 Что умеет:
1) Сканирует вакансии по заданным критериям.
2) Отправляет подходящие вакансии в указанного ТГ-бота.
3) Ведет список просмотренных вакансий, чтобы не отправлять повторы.

## 📝 Пример конфигурации:
```json
{
    "requestIntervalInSeconds": 10, // Интервал проверки новых вакансий
    "headHunter": {
        "baseUrl": "https://hh.ru",
        "apiUrl": "https://api.hh.ru"
    },
    "telegram": {
        "apiUrl": "https://api.telegram.org/bot",
        "botToken": "",
        "chatId": ""
    },
    "urlParameters": [ // Можно добавлять необходимые параметры для фильтра в массив
        {
            "key": "area", // query-параметр запроса
            "value": "113", // значение параметра
            "description": "113 = Россия (по справочнику HH)"
        }
    ]
}
```
